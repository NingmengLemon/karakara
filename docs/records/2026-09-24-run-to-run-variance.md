# 记录：同一首歌跑两次，结果不一样（2026-09-24）

> 这是**一次实测的记录**，不是规范。现状里的相关条目见
> [../current/limits.md](../current/limits.md)。

## 现象

同一首歌、同一条命令、同一个对齐服务，连着跑两次，产物不同：

| 文件 | 大小 | 时间标签数 |
|---|---|---|
| `default.kara.lrc`（第 1 次） | 4902 B | 304 |
| `default2.kara.lrc`（第 2 次） | 4924 B | 更多 |

逐标签比较：**221/304 个标签不同**，最大差 **12.4 秒**。这不是抖动。

## 隔离实验：差异来自分离，不是对齐

1. **对齐是确定的。** 同一段音频、同一行文本，向 HubertFA 服务连发 3 次：

   ```
   第 1 次：14 个单元，前两个 [('君', (400, 707)), ('が', (838, 1187))]
   第 2 次：14 个单元，前两个 [('君', (400, 707)), ('が', (838, 1187))]
   第 3 次：14 个单元，前两个 [('君', (400, 707)), ('が', (838, 1187))]
   三次完全一致: True
   ```

2. **分离不是确定的。** 同一首歌分离两次，两条人声轨：

   ```
   形状 (2, 9633071) vs (2, 9633071)
   最大样本差 0.424450，平均 0.005066，相关系数 0.998345
   ```

   差异**不是时间平移**：取中段 40 万采样做互相关，最佳滞后 **0 个采样**（±2000 采样范围
   内），按最佳滞后对齐后中段最大差 0.076、平均 0.0015。

3. **把分离换成固定输入，产物就逐字节一致了。** 用一个「不做分离、只把一份固定人声复制
   过去」的假 worker（`tmp/fixed_vocals_worker.py`）配合 `--separator-cmd` 跑两次：

   ```
   fixed1.kara.lrc  f7b03657948e63e3  4891 B
   fixed2.kara.lrc  f7b03657948e63e3  4891 B   ← 逐字节一致
   default.kara.lrc 36405f717701ad7f  4902 B
   default2.kara.lrc 952756827dfe3da4 4924 B   ← 真实分离，两次不同
   ```

所以：**给定同一份人声轨，整条流水线（预处理 → 偏移 → 切段 → 对齐 → 序列化）是确定的；
全部 run-to-run 差异来自分离那一步。**

## 原因

Demucs 跑在 CUDA 上。worker 调用的是 `demucs.api.Separator.separate_tensor()`，其
`shifts` 默认是 1（`shifts > 1` 才会做随机时间平移平均，实测滞后为 0 也印证了这一点），
所以**不是 Demucs 自己的随机性**，而是 GPU 侧的浮点非确定性（cuDNN 选核、并行归约顺序）。
幅度噪声很小（中段最大 0.076、相关 0.998），但对齐器在**边缘行**上很脆：输入差一点点，
某一行的切分就可能翻掉，于是那一行之后的边界整体位移（与 V4 记录里「错一个字就从错处往后
全毁」是同一类脆弱性）。

## 影响

- **单次产物的边界不该被当成精确值。** 同一首歌重跑一次，个别行的边界可能差几秒。
- **自动估计、按行裁剪这类「看能量做判断」的功能都会继承这份方差**：它们读的是同一条
  人声轨，而那条轨每次都不一样。
- 这也意味着：使用者感觉到的「误判」，有一部分可能不是判据错，而是**这一跑的人声轨**
  与上一跑不同。

## 可能的缓解（尚未实现）

1. **缓存分离人声并复用**：`scripts/check_aligner_stability.py` 已经是这个做法
   （`tmp/perturbation/<音频名>_vocals.wav`），主流水线每首歌都重跑分离。缓存之后同一首歌
   的重跑就是逐字节一致的（上面第 3 条已经证明）。
2. **让分离确定性**：worker 里加 `torch.use_deterministic_algorithms(True)`（可能变慢，或
   对某些算子不支持）。
3. **接受它，但把方差纳入判据**：任何「改进了吗」的比较都要在同一份人声轨上做（A/B 共用
   分离结果），否则量到的是分离噪声。

## 复现

```powershell
uv run python tmp/probe_determinism.py        # 分离两次 + 同一段对齐三次
uv run python tmp/probe_determinism_lag.py    # 差异是幅度噪声还是时间平移
uv run python tmp/compare_offset_outputs.py   # 两次产物的逐标签差异

# 固定人声跑两次（证明流水线本身确定）
uv run main.py -l song.lrc -a song.mp3 -o out1.kara.lrc `
  --separator-cmd .venv\Scripts\python.exe tmp\fixed_vocals_worker.py
```

原始产物在 `tmp/offset_verify/`，人声轨在 `tmp/determinism/`（都在 gitignore 内）。
