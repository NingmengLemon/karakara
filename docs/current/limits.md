# 已知限制

这一页只列**现在还成立**的限制与副作用。已经修好的东西在
[../archive/changelog.md](../archive/changelog.md)，某条限制的实测依据在 [../records/](../records/)。

## 会影响产物质量

- **零长度单元与精度下限取决于后端。** 默认的 HubertFA 帧移 10ms，实测日文零长度单元 1.9%、
  行区间覆盖率 88.8%；可选的 `qwen3` 量化在 80ms，零长度单元 22.5%（逐首 10.7% 到 41.8%）。
  处理方式见 [aligner.md](aligner.md)。
- **歌词错一个字的代价是「从错处往后全毁」。** 扰动点**之前**的边界漂移在日文上恒等于 0，
  错处**之后**的中位漂移 329 到 519ms、p90 约 2.1 秒。HubertFA 从左到右锚定，没有「只取最优
  连续子序列」那种容错，所以 VOCALOID 的错字与重复段落会命中这个坑，而且**产物上看不出
  异常**（覆盖率与单调性都正常）。遇到就手工修歌词，或用 `--target-lang` 跳过该行。
- **分离质量比片段边界重要得多。** 片段两端各加减 100ms 时行内边界中位只漂 1ms；把分离
  人声换成原始混音，中位漂 18.5ms、p90 398ms（日文）。想再提高质量就换更好的分离模型，
  不要调切段。
- **行尾可能拖进间奏。** 送给对齐器的片段是 `[本行起点, 下一行起点)`，而 HubertFA 的输出是
  对整段的连续划分，最后一个单元会吃掉剩下的时间；产物的行尾就是它的结束时刻。所以当一行
  唱完之后还有长间奏时，这一行的高亮会一直拖到间奏结束。实测 333 行里 5 行（1.5%）的行尾
  晚于人声结束 1 秒以上，最严重的一例晚了 88 秒；**最后一行**尤其容易（它的窗口右端是音频
  末尾，命中率是其余行的 30 倍）。`--trim-line-tail` 可以修掉这类情形（默认关闭，参数、
  守卫与实测效果见 [aligner.md](aligner.md)；评估过程见
  [records/2026-09-23-line-tail-trimming.md](../records/2026-09-23-line-tail-trimming.md)）。
- **全局偏移估计不可靠。** 两条判据各自都会错且错在不同的歌上，所以自动偏移极度保守
  （证据不足就不动）。见 [offset.md](offset.md)。
- **LRC 与音频版本不匹配时无解。** 歌词与音频属于不同剪辑时任何全局常量偏移都不成立，
  这类输入**需要人工发现**（`--offset` 或先看 `--dump-dir` 的产物）。
- **偏移估计存在可辨识性平台**：密集行首整体落在同一个长人声区间内时，区间内存在无法区分
  的平台，结果由平局规则决定。该估计器只有全局常量偏移一个自由度，处理不了逐行漂移。

## 行为与副作用

- **元数据行仍然充当切段边界**，这是刻意的（摘掉它们反而会让切段变长、把器乐段圈进去）。
  见 [metadata-filter.md](metadata-filter.md)。
- **`--dump-dir` 会为每一行歌词导出一个 WAV**（`05_line_<i>.wav`），一首歌几百个文件。
- **`--min-vocal-activity` 是相对阈值**：它用的是按峰值归一化到 1 的能量曲线，所以一首歌
  只要有一个响的副歌，安静的主歌就可能整段被跳过。
- **「X by Y」这条自定义模式有理论上的误伤面**：英文歌词 `Sound by the sea` 这类会被判成
  署名。本库实测 0 例，真遇到就删掉 `[custom] patterns` 里那一条。

## 工程

- **没有 CI。** `ruff` / `mypy` / `ty` / `pytest` 都配好了，但仓库里没有 workflow，
  四个检查都得手动跑。
- **`samples/` 下有音频二进制入库**（约 19MB），版权归各自的原始创作者所有。
- **`audio-separator` 后端的模型清单查询要联网**：`--list-models` 需要访问
  `raw.githubusercontent.com`，被墙时只能直接给 `--separator-model`。
- **第三方代码与模型不进仓库**：`third_party/HubertFA` 是 submodule（首次使用要
  `git submodule update --init`），`models/` 被 gitignore。换台机器要各自准备。
