# 偏移对照工具（GUI）

`scripts/offset_gui.py`。它解决一件事：**这份歌词整体偏了多少**。左边是波形（人声在什么时候
进来），右边是歌词每行的起点，挪到对得上，然后写回歌词文件。

它**不**做分离、不做对齐、不生成逐字产物，也不处理逐行漂移（那需要重新对齐，属于 CLI 的活）。

它是**拿到偏移的推荐方式**：自动估计默认关闭（实测误判偏多，见 [offset.md](offset.md)），
而对着波形看「人声什么时候进来」比读一个估计值可靠。用这个工具定好偏移后，要么把偏移量
抄给 CLI 的 `--offset`，要么直接在这里写回歌词文件。

## 跑起来

```bash
# 歌词 + 音频（音频缺省时自动找同目录同名的 wav/mp3/flac/m4a）
uv run --group gui python scripts/offset_gui.py song.lrc --audio song.flac

# 带分离人声（推荐）：混音波形几乎铺满全曲，看不出起唱点
uv run --group gui python scripts/offset_gui.py song.lrc --audio song.flac \
  --vocals tmp/perturbation/song_vocals.wav

# 起手就带一个初值（例如 CLI 提示的那个 --offset）
uv run --group gui python scripts/offset_gui.py song.lrc --offset -120

# 只建窗口画一帧就退出（自检，不需要人工介入）
uv run --group gui python scripts/offset_gui.py song.lrc --audio song.flac --selftest
```

`--vocals` 缺省时会自动找：音频同目录的 `<名字>_vocals.wav` / `<名字>.vocals.wav` /
`<名字> (Vocals).wav`，以及扰动稳定性工具的缓存 `tmp/perturbation/<名字>_vocals.wav`。
有它时画面上是「混音画暗 + 人声画亮」，起唱点一眼可见。

## 操作

| 动作 | 怎么做 |
|---|---|
| 播放 / 暂停 | 空格，或「播放」按钮 |
| 反复听当前行 | 勾上「循环本行」，或点「试听本行」 |
| 换行 | 「上一行」/「下一行」，或 `[` `]`，或直接点歌词列表 |
| 微调偏移 | `,` / `.`（±10ms），或 `-100` / `-10` / `+10` / `+100` 按钮，或直接在输入框里填 |
| 定位 | 点画布；拖动平移；滚轮缩放；左右方向键 ±1 秒 |
| 写回 | 「写回歌词文件」（或 `s`）；另存为用 `Ctrl+S` |

画面上的竖线是每行歌词的起点（当前行是红线并带浅色底），黄线是播放头，底下一行是时间刻度。

## 写回歌词文件时发生了什么

写回的是**文本级平移**：只把时间标签里的数字加一个偏移量，其余内容一个字节都不动。
这样用户的歌词文件里的翻译行、特殊标签、奇怪空白、CRLF 都不会被规范化掉。具体行为：

- **原子替换**：先写同目录的临时文件再 `os.replace`，中途失败不会留下半截文件。
- **备份**：写入前的内容复制成 `<文件名>.bak`（每次写回都覆盖它，等于一层撤销）。
- **编码保持**：按 UTF-8 / GB18030 / CP932 依次严格试解，写回时用同一个编码，不把 GBK
  的歌词悄悄转成 UTF-8；换行风格与 BOM 同样保持。
- **负数夹取**：平移后为负的时间戳夹到 0，并在完成提示里报告夹了几个。
- **写回后偏移清零**：文件已经落在新时间轴上了，界面上表现为「标记仍在原处、文件已对齐」。
  不清零的话第二次保存会把同一个偏移再叠一次。
- **另存为**不建 `.bak`，也不读目标文件（用内存里的原文平移）。

写回前会弹确认框，写明目标路径与偏移量。

## 依赖边界

`tkinter` 是标准库；只有**播放**需要 `sounddevice`，它在 `gui` 依赖组里
（`uv run --group gui ...`）。缺这个包或机器没有输出设备时，界面会在顶栏写明原因，
禁用播放按钮，波形、缩放、偏移、写回全部照常可用。

## 实现位置

| 模块 | 职责 |
|---|---|
| `karakara/gui/peaks.py` | 波形包络与「时间 ↔ 像素」聚合（纯 numpy） |
| `karakara/gui/lrctext.py` | 文本级时间戳平移（原地写回的地基） |
| `karakara/gui/session.py` | 会话状态、音频载入、安全写回（不 import GUI 库） |
| `karakara/gui/player.py` | 播放（`sounddevice`，可选） |
| `karakara/gui/app.py` | tkinter 界面 |

逻辑都在前四个模块里，界面只负责画和收事件，因此它们都能在没有人工介入的情况下测。
